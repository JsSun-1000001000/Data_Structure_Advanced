# Hash Table（散列表）

功能：无序数据，快速搜索$O(1)$

哈希表可以直接使用 `unordered_map / unordered_set` 

## hash table的底层实现

散列：按照数据的某种特性进行分组

**建哈希表：**
1. 确定==散列函数== 常用：`p = key % M` 其中，M一般取质数，并小于等于N（理论上），实际都是大于N的。（建议了解`unordered_map / unordered_set`是怎么实现的）
2. 解决==哈希冲突==的办法（一组来了俩人）
	- ==开放地址法==：尽量不产生冲突的前提下才会用（不咋用）
		- ==线性探测==：沿着当前元素的位置向后移动直到由空位置
		- ==线性补偿探测==：往后跳着找，一般不用，容易死循环
		- ==二次探测==：按照$\pm1 \pm4 \pm9 \pm16 \pm25$顺序探测
	- ==**拉链法**==：数组挂着链表，来都来了，用链表形式链下来，对冲突的情况友好

**哈希表建立要什么：**
1. 节点类
	- value
	- next
2. 哈希表
	- 地址数组（M个 nullptr）
	- 完成元素添加：先用哈希函数获得对应组；向该链表中进行节点添加； 

```cpp
#include <iostream>
#include <vector>
using namespace std;

#define M 11

class node
{
public:
	int value;
	node* next;
	node(int num) :value(num), next(nullptr) {}
};

class HashTable 
{
public:
	vector<node*>hash;
	HashTable() :hash(M, nullptr) {}
	void CreateHash(vector<int>&nums) 
	{
		int len = nums.size();
		if (len == 0) return;
		for (int v : nums)
		{
			//申请节点
			node* tmp = new node(v);
			//位置确定
			int index = v % M;
			//链表结点的通知
			tmp->next = hash[index];
			hash[index] = tmp;
		}
	}
	void Search(int num)
	{
		int index = num % M;
		node* tmp = hash[index];
		//遍历链表
		while (tmp)
		{
			if (tmp->value == num)
			{
				cout << "success" << endl;
				return;
			}
			tmp = tmp->next;
		}
		cout << "failed" << endl;
	}
};
int main()
{
	vector<int>nums = { 12,44,13,88,23,94,11,39,20,16,5 };
	HashTable ht;
	ht.CreateHash(nums);
	ht.Search(12);
	ht.Search(44);
	ht.Search(100);
	return 0;
}
```

## 哈希表实现的优化

**装载因子：**$\alpha = \frac{元素个数}{表长}$，在线性探测里，$\alpha < 0.7 ~ 0.8$
